# 政治经济学期刊 Zotero 引文样式

本合集收录 28 种经济学与政治经济学期刊引文样式，并附 4 个依赖样式。合集包含基于期刊规范或已刊样例定制的样式，以及来自 CSL 仓库和 Zotero 中文社区的现有样式。

## 安装

下载所需的 `.csl` 文件，在 Zotero 的「设置 → 引用 → 样式」中点击「+」安装。若所选样式依赖父样式，先安装对应的父样式。随附的父样式为 APA、Elsevier Harvard、Springer Basic (author-date) 和 Taylor & Francis Chicago (author-date)。
